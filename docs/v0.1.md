## What it does
- **Home:** one big START button (~46% of the screen). One tap stores the time, no questions.
- **Running:** big timer; "started earlier" chips (5/15/30/60 min, pick time); STOP in the same
  place; quick-add O2 / triptan; "wrong tap? undo" for 10 seconds; "Still going?" after 3 h.
  Tabs are hidden while an attack runs so STOP is the obvious target.
- **After STOP:** "Exact end time" (with "actually ended 5/15/30/60 min ago" or a time box) or
  **"In sleep / not sure"** → "Don't know" or a rough time in 15-minute steps (stored as
  `end_confidence: approx`). "Same as last time", then all-optional chips: worst pain, side, woke
  me / was awake, treatments (O2 flow + mask), did it work + relief after N min, symptoms,
  triggers, note. Every tap saves; there is no Save button.
- **History:** attacks-per-day bars (14/30/90 days, coloured by worst pain), list by day, tap to
  edit or delete. CSV download. **Doctor summary**: counts, median duration, mean pain, % at night,
  side, treatment relief table, attack table; prints / saves as PDF.
- **Settings:** theme (auto / light / dark / **night** — extra dim), my treatments, bout gap,
  backup download / restore (JSON), delete everything, install instructions.
- **Offline:** service worker precaches the whole app; opens with no network. Asks the browser
  to keep data (`navigator.storage.persist()`).
- **Android:** long-press the icon → "Start attack" starts one straight away.
- **Research fields:** every attack keeps `start_source`, `end_source`, `end_confidence` and
  `recorded_fields_at` (when each field was entered), ready for v1.0 donation.

## Not in v0.1 (by plan)
Accounts and sync, preventive log, notifications, bout merge/split, the optional research profile
(year+month of birth etc.) and donation pipeline — those wait for v0.2 / v1.0 and the stichting +
DPIA decisions.

## Run, test, deploy
```
npm install
npm run dev        # http://localhost:3000
npm test           # unit tests (logic + local database)
npm run typecheck
npm run build      # static export to out/ + out/sw.js
```
Deploy `out/` anywhere static. **Vercel:** import the repo (framework Next.js, defaults).
**Cloudflare Pages:** build command `npm run build`, output directory `out`.
Then open the URL on your phone and add it to the Home Screen.

Icons: `node scripts/icons.mjs` re-renders the PNGs from `public/icon.svg` (needs Playwright).

## Known limits
- iPhone: no long-press shortcut and no vibration for web apps; Safari may clear data for sites
  not used for weeks — install to Home Screen and download a backup now and then.
- Medians use the lower middle value for even counts.
